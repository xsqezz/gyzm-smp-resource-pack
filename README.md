# Gyzmo SMP — Gemy

Oficjalny resource pack serwera Gyzmo SMP dla pluginu `smp-paper-plugin` w wersji 1.2.7.

Paczka `Gyzmo-SMP-Gemy-1.2.7.zip` dodaje trzynascie unikalnych tekstur Echo Shardow dla Gemow. Kazdy Gem ma inny kolor i symbol powiazany ze swoja zdolnoscia.

## Konfiguracja serwera

Wpisz bezposredni adres assetu z wydania do pola **Resource pack** w panelu serwera albo ustaw w `server.properties`:

```properties
resource-pack=https://github.com/xsqezz/gyzm-smp-resource-pack/releases/download/v1.2.7/Gyzmo-SMP-Gemy-1.2.7.zip
resource-pack-sha1=e947c436e16c600b3f7a49913c58032546ad89f5
resource-pack-prompt={"text":"Gyzmo SMP wymaga resource packa Gemow."}
resource-pack-required=true
```
